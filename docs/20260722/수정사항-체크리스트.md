# AR-pic 레이아웃 V3 — 수정사항 체크리스트

> 출처: `docs/20260722/AR-PIC 레이아웃 V3_page-0001~0016.jpg` (가로형 8장 + 세로형 8장)
> 대체로 **레이아웃(버튼 크기·위치) 변경 / UI·사용자 flow 개선 / 세로형(반응형) 레이아웃** 관련.

## 범례
- `[ ]` 미착수 · `[x]` 완료 · `[~]` 부분 반영
- 🔴 = 시안에 적힌 빨간 주석(검토·논의 필요 사항)
- (✔ 반영됨) = 이번 작업분에서 이미 처리된 항목

화면 순서(사용자 flow): **START → 결제(매수) → 컷 구성 → 배경 → 촬영 → 인화사진 선택 → 프레임 배경 → QR/인화**
각 화면은 가로형(page 1–8)과 세로형(page 9–16)이 쌍으로 있음.

### 확정된 방향 (2026-07-24)
- **세로형 = 화면 비율 반응형** — 물리적 세로 키오스크 전용이 아니라, **뷰포트 가로<세로일 때 세로 레이아웃**으로 전환.
- **가격 = 티어별 개별가** — 수량마다 개별 가격(예: 1장 5,000 / 2장 9,000 / 4장 18,000, 할인 포함). 장당×수량(선형) 아님.
- **"장"(결제 매수)과 "컷"(레이아웃)은 독립 축** — 장 = 인쇄 매수(부수), 컷 = 프레임 배치(1/2/4컷). 결제가 컷보다 앞 단계이므로 가격은 컷과 무관하게 매수로만 결정.
- **촬영**: 스티커 패널 상시 노출 / 촬영 직후 촬영본 0.5초 표시 / "다음"은 컷 수 이상 촬영 전까지 비활성.
- **인화 선택**: 기존 로직 유지(컷 수 기반 선택). **컷 구성 1컷 비율**: 기존 그대로(관리자 설정).
- **QR/인화**: 좌우 반반(12컬럼 중 6/6). **테마관리**(primary·로고): 전역·서비스 화면 적용.
