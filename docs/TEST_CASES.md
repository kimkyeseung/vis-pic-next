# AR-pic 테스트 케이스 (QA Test Cases)

> **대상 버전:** 0.1.0 · **작성일:** 2026-07-26 · **기준 문서:** `SPEC.md`
> 사용자(고객) 플로우 → 교차 항목 → 시스템 → 관리자 패널 순으로 구성.

---

## 1. 테스트 환경 및 사전 준비

| 항목 | 내용 |
|------|------|
| 실행 형태 | ① Tauri 데스크탑 앱(WebView2, 권장) ② 브라우저 직접 실행(`/service?device={id}`) |
| 대상 해상도 | 1920×1080 전체화면 (키오스크). 세로 설치 시 portrait 레이아웃도 확인 |
| 필수 하드웨어 | 웹캠, (선택) 보조 모니터, (선택) 프린터, (결제 테스트 시) PayApp 단말 |
| 테스트 장치 | 최소 2개 지점(deviceId) — 지점별 설정/배경/가격 분리 확인용 |
| 계정 | 관리자 계정 1개 이상 (`/admin/login`) |
| 네트워크 | 온라인 1회 + 오프라인(랜선 분리) 1회 |
| 초기화 | 각 케이스 사이 대기 화면 복귀(재시작) 또는 세션 초기화 권장 |

**사전 데이터 세팅 체크**
- [ ] 테스트 지점에 촬영 배경(type 1) 1~6개 연결·정렬 완료
- [ ] 인쇄 배경/프레임(type 2) 유·무 두 케이스 모두 준비 (PBG 단계 분기 확인용)
- [ ] `PAYMENT_ENABLED` on/off 두 지점 준비
- [ ] `CHROMAKEY_MODE` = mediapipe / chromakey / chromakey-yuv / off 전환 가능하도록 확인
